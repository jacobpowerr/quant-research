# Fractal Analysis of Financial Time Series

## Overview

This project investigates whether the Hurst exponent captures statistically unusual or predictively useful structure in financial-market returns.

Daily data from 20 ETFs were analyzed using full-sample and rolling Hurst estimates. The estimates were compared with IID Gaussian null models, and rolling Hurst was subsequently tested as a feature for predicting trend continuation.

The project was conceptually motivated by the work of Benoit Mandelbrot and Edgar E. Peters on fractal behaviour and long-range dependence in financial markets.

## Research Questions

1. Do ETF returns produce Hurst estimates that differ significantly from estimates generated by IID Gaussian noise?
2. Does the behaviour of rolling Hurst differ from an IID Gaussian null model?
3. Does rolling Hurst improve out-of-sample predictions of trend continuation beyond momentum and volatility?

## Data

The dataset contains daily closing prices for 20 ETFs representing equities, bonds, commodities, currencies, and real estate:

`DBA`, `DBC`, `EEM`, `EFA`, `FXE`, `FXY`, `GLD`, `HYG`, `IEF`, `IWM`, `LQD`, `QQQ`, `SLV`, `SPY`, `TLT`, `USO`, `UUP`, `VNQ`, `XLE`, and `XLK`.

The common price sample begins on February 6, 2006. All Hurst estimates were calculated from daily log returns.

## Methodology

The project consisted of three experiments:

1. **Full-sample null test**
   - Calculate one Hurst estimate for each ETF.
   - Generate 1,000 IID Gaussian return series of equal length.
   - Compare the observed estimates with the simulated null distribution.
   - Apply a Bonferroni correction for testing 20 ETFs.

2. **Rolling-Hurst null test**
   - Calculate Hurst using rolling 252-trading-day windows.
   - Generate rolling-Hurst distributions from 100 IID Gaussian simulations.
   - Compare the mean, standard deviation, minimum, and maximum of each ETF’s rolling-Hurst series with the corresponding null distributions.

3. **Predictive experiment**
   - Predict whether the current 63-day price direction continues over the following 21 trading days.
   - Compare a baseline logistic regression using momentum and volatility with an expanded model that also includes rolling Hurst.
   - Use chronological training, validation, and test periods separated by 21-day gaps.
   - Evaluate performance using log loss, ROC AUC, and accuracy.

## Results

### Null-model analysis

No full-sample Hurst estimate remained statistically significant after correcting for multiple comparisons.

The rolling analysis identified potentially unusual behaviour in XLK and GLD, but no result passed the corrected significance threshold. Because only 100 rolling simulations were performed, this analysis should be treated as exploratory.

### Predictive performance

| Test metric | Naive benchmark | Baseline model | Hurst model |
|---|---:|---:|---:|
| Accuracy | 0.5023 | 0.5263 | 0.5211 |
| Log loss | — | 0.6921 | 0.6926 |
| ROC AUC | — | 0.5615 | 0.5563 |

The baseline model modestly outperformed the naive accuracy benchmark. Adding rolling Hurst worsened all three test metrics.

## Conclusion

Under the specific assets, historical period, estimator, parameters, and predictive model tested, the Hurst exponent did not demonstrate reliable statistical or incremental predictive value.

This result does not establish that Hurst is universally uninformative. It shows that the 252-day rolling Hurst feature did not improve 21-day trend-continuation predictions beyond momentum and volatility in this experiment.
